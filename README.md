# 📌 Projeto em Destaque

## 💰 Expense Control System

Sistema Full Stack para gerenciamento de gastos desenvolvido como desafio técnico.

### Tecnologias

- ASP.NET Core
- C#
- Entity Framework Core
- SQLite
- React
- TypeScript

### Funcionalidades

- Cadastro de pessoas
- Cadastro de receitas e despesas
- Relatórios financeiros
- Dashboard
- Gráficos
- Regras de negócio
- Deploy completo
